# Cheatsheet — Scaling Up (Harnish)

## Decision rules
| When | Do | Because |
|---|---|---|
| Don't know where to start | 4 Decisions Assessment, start with weakest | leaders favor the decision they like |
| Whole team overwhelmed | 1-2 Habits per quarter, 1 chapter/month | all ten at once stalls adoption |
| Function has no owner | add ONE accountable name on the FACe | "all of us" = none of us |
| Hiring a key role | Job Scorecard + Topgrading, never gut | gut hits 25-60%, Topgrading 90%+ |
| Candidate ranking | Will > Values > Results > Skill | skills are cheapest and age fast |
| Strategy sounds generic | rewrite Brand Promises as measurable, add a guarantee | "quality/service" is unmeasurable |
| Target missed | repeat it, move on, or fix one root cause | never move the goal mid-quarter |
| Huddle is dying | ban problem-solving, demand specifics | brain cannot pattern-match generalities |
| Growth drains cash | CASh brainstorm; date invoices, don't write "net 30" | payables pay on sign-off date |
| Need to pick financial lever | Power of One, working-capital levers first | they hold most of the cash |
| Margins erode | Gross Margin Dollars by customer (waterfall), cut losers | losers are not "strategic" |

## Decision tree: which Decision first?
- Talent or culture problems → **People** (FACe, Scorecard, Core Values)
- Can't state strategy simply → **Strategy** (7 Strata, OPSP)
- Drama, missed dates → **Execution** (Critical Number, Data, Rhythm)
- Cash tight or profit thin → **Cash** (CCC, Simple Numbers)

## Thresholds and defaults
| Item | Number |
|---|---|
| Core Values | 3-8 |
| Rocks per quarter | 3-5, one owner each |
| Brand Promises | 3, one leading |
| Key Thrusts | 3-5 (3-5 year horizon) |
| Planning horizon | BHAG 10-25 yrs; OPSP 3-5 yrs / 12 mo / 90 days |
| Applicants per opening | ≥ 20:1 |
| Recognition ratio | 3 positive : 1 negative |
| Daily huddle | ≤ 15 min, ~1 min/person |
| Weekly meeting | 30 min frontline; 60-90 min managers |
| Training budget | 2-3% of payroll |
| Outside exec hires | one every 6-9 months |
| Pretax profit | 5% life support · 10% good · 15% great · >15% harvest |
| Core Capital Target | 2 months opex in cash |
| Culture drift | ~50-70 employees |
| Matrix structure | beyond ~50 employees |

## Tells and smells
- Founder in 3-4 FACe boxes → burnout or under-supported functions
- Monthly billing + twice-monthly payroll → structural cash gap
- Revenue and profit up, cash down → "growing broke"
- Values only on the wall → HR systems not aligned
- Metrics reviewed monthly only → warnings arrive late (weekly trend charts)
- Feedback gathered, no reply → employees stop giving it
